# Security Policy

## Supported Versions

Security updates are provided for the latest released version of Internet Traffic Controller.

Older versions may not receive security updates. Users are encouraged to download and use the latest version from the official GitHub repository or official releases.

## Reporting a Vulnerability

If you discover a security vulnerability in Internet Traffic Controller, please **do not report it publicly through GitHub Issues**.

Instead, use GitHub's **Private Vulnerability Reporting** feature for this repository.

When submitting a report, please include as much information as possible:

* A clear description of the vulnerability.
* Steps required to reproduce the issue.
* The affected version of Internet Traffic Controller.
* The potential impact of the issue.
* Any relevant screenshots, logs, or other helpful information.

Please do not include passwords, personal information, or other sensitive data in your report.

## What Happens Next

After receiving a vulnerability report, I will review and investigate the issue.

If the issue is confirmed, I will work to address it when reasonably possible. Depending on the severity and complexity of the issue, a security update may be released.

Response and fix times may vary depending on the nature of the vulnerability.

## Security Best Practices

Users should:

* Download Internet Traffic Controller only from the official GitHub repository or official releases.
* Keep the application updated to the latest available version.
* Avoid downloading modified or unofficial versions from third-party sources.
* Review network-related actions before using them.
* Use administrator privileges only when required by a feature.

## Scope

This security policy applies to the official Internet Traffic Controller application, its source code, and official releases.
